Memao Villagers - Split Asset Pack
====================================

10 fantasy villager characters, each with 14 animation strips.
Every strip is 192x48px (four 48x48 frames, left to right).

Folders: one per character (villager_female_cap, etc.)
Files per character:
  idle_down, idle_up, idle_left, idle_right  - standing
  walk_down, walk_up, walk_left, walk_right  - walking
  work_down, work_up, work_left, work_right  - axe/tool chop
  emote_wave, emote_cheer                    - front-facing emotes

The 48x48 cell size matches the Serene Village tileset (48x48),
so villagers sit correctly on the 8x8 grid.
